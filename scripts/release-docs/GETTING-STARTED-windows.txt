Invo Sentinel - Windows quick start
===================================

What's in this folder:

  start.bat   <- run this one. Double-click it. Starts everything.
  bin\        <- the daemon program and its data/logs live in here - you
                 don't need to touch anything in this folder directly.
  ui\         <- the dashboard's own files - also not meant to be opened
                 directly, start.bat handles it.
  .env.example
  README.md   <- the full project documentation (setup wizard, risk
                 config, dashboard UI, troubleshooting, everything).

1. Double-click start.bat.

   A console window opens and stays open while Invo Sentinel runs -
   closing that window stops everything. start.bat starts both the daemon
   and the dashboard UI, and automatically restarts the daemon if it ever
   crashes - leave the window open.

   The dashboard UI needs Node.js installed (get it from nodejs.org) - the
   daemon itself needs nothing and will start regardless. If Node isn't
   found, start.bat says so and starts the daemon on its own; install Node
   and re-run for the UI too.

2. Your browser should open to the dashboard automatically after a few
   seconds (http://localhost:4400). If it doesn't, just open that address
   yourself.

3. On first run, nothing is configured yet - the daemon just waits (it
   will NOT crash or close) and the dashboard shows a short setup wizard
   for the 3 required values (Invo refresh token, Hyperliquid agent key,
   wallet address). Alternatively, hand-edit a .env file placed in this
   same folder, next to start.bat (see README.md's "Credentials" section
   for the same 3 variables). Either way, the already-running daemon picks
   up the values automatically within a few seconds - no restart needed.

4. Want it to run in the background instead of keeping a console window
   open? Run:  start.bat --background
   Want it to start automatically when you log in or reboot? See the
   "Running continuously" section of README.md for a Startup-folder
   shortcut or Task Scheduler.

Everything else - risk configuration, the dashboard UI, auditing tools,
troubleshooting - is documented in README.md in this same folder.
